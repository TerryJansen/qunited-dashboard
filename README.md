# Qunited Operations Dashboard

A responsive Dutch-language dashboard prototype for an oil and gas operations team.

## Start locally

```sh
npm install
npm run dev
```

## Verify / build

```sh
npm test
npm run build
```

The dashboard includes quick links and overview screens for projects, materials, invoices, IT support, inventory, and procedures. Current metrics, projects, and quick-link destinations are demo data/placeholders. Connect these modules to approved company systems and data sources before operational use.
